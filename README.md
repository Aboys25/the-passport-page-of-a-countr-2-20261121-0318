# The passport page of a country that isn't there

An open passport spread for the invented island Republic of Selvaria:
holder Elena Maris Voss, lighthouse keeper of North Ferry, born in Port
Meridian. `main.py` (Python 3.13, standard library only, no network)
draws the spread — portrait, stamps, travel history and a 44-character
ICAO MRZ — to `entry.png` (1024x720) in the output directory. Fully
deterministic: every run writes the exact same bytes (48,023 bytes).
